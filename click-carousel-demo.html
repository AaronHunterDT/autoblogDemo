Click Carousel Demo

A dedicated inventory carousel experience that leans on query-string preselection and a hard-coded ZIP of 75001, so the demo opens directly to Jeep Grand Cherokee inventory with stronger result density.

Why this page exists

This page replaces click-carousel customization controls with a purpose-built demo route. Per the widget docs, the carousel can read make, model, and ZIP from the URL when use-qs is enabled, which is a cleaner demo pattern than trying to customize the carousel like the other widgets.

  • URL defaults this page to Jeep Grand Cherokee.
  • The widget enables query string overrides via use-qs.
  • ZIP 75001 is hard-coded on the widget for better inventory coverage.
  • The embed uses widget.js instance rendering so the page fits the dynamic loading guidance for SPA-like demos.
